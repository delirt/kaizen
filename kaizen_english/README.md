# 🌱 Kaizen English

Telegram-бот для школьников 7–11 классов: английские слова по чуть-чуть каждый день (≈5 минут),
с ассоциациями, короткими заданиями и интервальными повторениями. Интерфейс — на русском.

> Философия кайдзен: учись понемногу каждый день — запоминай больше со временем.

## Что умеет

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и вход |
| `/today` | Урок дня: 2 новых слова (можно 3), задание после каждого, затем повторение слов, у которых подошёл срок |
| `/review` | Ручное повторение слов, которым пришло время |
| `/tasks` | 3–4 дополнительных задания на разных словах (открываются после урока дня) |
| `/progress` | Выучено слов, за неделю, успешно повторено, серия дней, ждут повторения |
| `/settings` | Уровень, 2/3 слова в день, напоминания и время |
| `/reset` | Сброс прогресса — только после подтверждения |
| `/feedback` | Оставить отзыв: оценка 1–5, текст и согласие на анонимную цитату |
| `/help` | Справка |

Команды владельца (в меню не показываются): `/myid` — ваш Telegram id, `/stats` — сводная статистика
(пользователи, пройденные уроки, активные за 7 дней, средняя оценка), `/feedbacks` — последние отзывы без имён.
Чтобы они заработали, добавьте в `.env` строку `KAIZEN_ADMIN_IDS=<ваш id>` и перезапустите бота.
Новые отзывы также приходят владельцу сообщением. Статистика агрегированная — личных данных в ней нет.

Меню команд настраивается через Bot API (`setMyCommands` + `MenuButtonCommands`) при каждом запуске,
а любое текстовое сообщение возвращает пользователю нужные кнопки — «залипнуть» без `/start` невозможно.

### Как устроено обучение

* **Карточка слова:** перевод, английское определение, простое объяснение, пример с переводом и *одна лучшая ассоциация*
  (в данных у каждого слова 2–3 ассоциации, показывается выбранная `best`).
* **Задание после каждого слова:** перевод, русский → английский, пропуск в предложении, выбор слова по ситуации.
  Позиции ответов перемешиваются. При ошибке — объяснение-подсказка и вторая попытка (правильный ответ не раскрывается сразу);
  после второй ошибки или кнопки «🤷 Не знаю» бот показывает ответ. «▶️ Продолжить» доступно только после задания.
* **Дневной лимит:** слова дня фиксируются в БД при первом `/today`. Одна запись урока на пользователя и день
  (уникальный индекс), поэтому повторные нажатия и перезапуски бота новых слов не дают.
* **Интервальные повторения (SRS):** после изучения — повтор через 1 день, затем интервалы 3 → 7 → 14 → 30 → 60 → 120 дней.
  Верный ответ на «созревшем» слове повышает ступень; ошибка понижает ступень и возвращает слово уже завтра
  (+ слово получает ещё одну попытку в этой же сессии). Решает **первая** попытка в задании.
  Дополнительные задания не «накручивают» интервалы: по несозревшим словам верный ответ ничего не меняет, ошибка приближает повтор.
* **Честный прогресс:** слово считается «прочно запомненным» только после 5 успешных повторений с растущими паузами.
* **Доп. задания:** слова выбираются вперемешку из «пора повторить», «выучены сегодня» и «старые»; на разных словах
  и без одинаковых заданий. Если слов мало — используются только изученные, с разными типами заданий.

## Структура

```
kaizen_english/
├── main.py            # запуск, меню команд, регистрация хендлеров
├── config.py          # настройки из переменных окружения / .env
├── handlers/          # Telegram: команды, кнопки, напоминания
├── services/          # логика: learning (урок/повторение/практика), srs, exercises, clock
├── database/          # SQLite: db.py (подключение), migrations.py, repository.py (весь SQL)
├── content/           # words.py (словарь), texts.py (все русские тексты)
└── tests/             # unit/e2e-тесты и smoke-тест через python-telegram-bot
```

Слой `services` не зависит от Telegram (возвращает `Screen`/`Response`), поэтому тестируется без сети.

## Установка и запуск

Нужен Python 3.10+.

```bash
cd kaizen_english
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                    # впишите токен от @BotFather
python main.py
```

### Настройка (переменные окружения или `.env`)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен от @BotFather (**обязательно**, не храните в коде и git) | — |
| `KAIZEN_DB_PATH` | путь к файлу SQLite | `kaizen_english/data/kaizen.db` |
| `KAIZEN_TIMEZONE` | часовой пояс для «сегодня» и напоминаний | `Europe/Moscow` |
| `KAIZEN_LOG_LEVEL` | уровень логов | `INFO` |

`.env` и файлы `*.db` внесены в `.gitignore`.

## Хранение данных (SQLite)

Всё состояние — в одном файле БД: пользователи, настройки, прогресс по словам, расписание повторений и
**точная позиция внутри урока**. Поэтому бот переживает перезапуск, выключение компьютера и обновление кода:
после `/today` урок продолжится с того же места.

Таблицы: `users` (id, дата регистрации, уровень, состояние, дата последнего урока), `user_settings`
(слов в день, напоминания, время, режим `general`/`ielts`), `user_words` (слово, статус, первое изучение,
последнее/следующее повторение, верные/неверные ответы, ступень), `activities` (уроки/повторения/практика и их позиция;
«дневной прогресс» считается из них), `feedback` (отзывы; сброс прогресса их не удаляет).

**Миграции.** Версия схемы хранится в `PRAGMA user_version`. Новая структура добавляется *новой* записью в
`database/migrations.py` (старые не редактируются) и применяется автоматически при старте; перед миграцией
существующей БД создаётся копия `kaizen.db.bak-v<версия>-<время>`. Прогресс пользователей миграции не удаляют.

**Резервные копии.** Достаточно копировать файл БД (при включённом WAL — вместе с `-wal`/`-shm`, либо
выполнить `sqlite3 kaizen.db ".backup backup.db"`).

## Деплой

Бот работает через long polling — входящий порт не нужен, но **запускайте ровно один экземпляр** на токен.

**Главное правило: БД должна лежать на постоянном диске.** Файловая система контейнеров/PaaS обычно
временная — без volume прогресс пропадёт при каждом деплое.

* **VPS (systemd):** `KAIZEN_DB_PATH=/var/lib/kaizen/kaizen.db`, юнит с `Restart=always`, `EnvironmentFile=` с токеном.
* **Docker:** `docker build -t kaizen . && docker run -d --restart=always -e BOT_TOKEN=... -v kaizen-data:/data kaizen`
  (в образе `KAIZEN_DB_PATH=/data/kaizen.db`).
* **Fly.io / Railway / Render и т. п.:** создайте persistent volume, смонтируйте в `/data`, задайте `BOT_TOKEN` как
  секрет и `KAIZEN_DB_PATH=/data/kaizen.db`. Без volume не деплойте.
* Если понадобится несколько экземпляров или управляемая БД, слой `database/repository.py` — единственное
  место с SQL, его можно перевести на PostgreSQL.

## Добавление слов

Допишите словарь в конец `WORDS` в `content/words.py` (все поля обязательны; валидация запускается при импорте,
`id` не переименовывайте — на него ссылается прогресс пользователей). Новые слова сразу появятся в выдаче.
Сейчас в словаре 34 слова уровней A2–B2 — этого хватает примерно на 2 недели при 2 словах в день; для
реального использования словарь стоит расширять.

## Задел на будущее

* **Уровни:** выбираются при первом запуске и в `/settings`; смена уровня не стирает историю. Если слова
  выбранного уровня закончились, берутся ближайшие уровни.
* **IELTS:** у слов есть поле `track`, у пользователя — `mode` (`general`/`ielts`); кнопка в настройках пока
  показывает «скоро».
* **Напоминания:** уже работают (опционально, время выбирается в `/settings`, не чаще одного раза в день,
  не отправляются после завершённого урока). Нужен `python-telegram-bot[job-queue]` (есть в requirements).
* **AI-объяснения:** точки подключения — `services/exercises.py::wrong_answer_text` (объяснение ошибки) и карточка
  слова; бот полностью работает без AI API.
