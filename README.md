# kaizen

**Kaizen English** — Telegram-бот для ежедневного изучения английских слов (интервальные повторения, короткие
задания, ассоциации). Код и подробная документация — в папке [`kaizen_english/`](kaizen_english/README.md).

```bash
cd kaizen_english && pip install -r requirements.txt && cp .env.example .env   # впишите BOT_TOKEN
python main.py
```
